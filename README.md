# Store-GPS
Universal in-store product finder.

A simple, mobile-friendly web app that helps shoppers find any product and the
exact aisle it's in — in seconds. Built to feel effortless on a phone or an
in-store kiosk.

## Features
- 🔎 **Instant search** — results update as you type
- ⭐ **Popular shortcuts** — one-tap chips for common items
- 📍 **Aisle + section** for every product, with a live "Where to go" mini-map
- 🟢 **Stock status** at a glance
- 📱 Works on any phone, tablet, or kiosk — no install needed

## Run the demo
No build step required — it's plain HTML/CSS/JS.

```bash
python3 -m http.server 8090
# then open http://127.0.0.1:8090
```

## Files
- `index.html` — page structure
- `styles.css` — clean, responsive styling
- `app.js` — search logic and the sample product catalog
